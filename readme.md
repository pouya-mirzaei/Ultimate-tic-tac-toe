# Super Tic-Tac-Toe

A strategic implementation of **Super Tic-Tac-Toe** featuring an AI opponent powered by the **Minimax algorithm**.

## Overview

Super Tic-Tac-Toe is an advanced version of the classic Tic-Tac-Toe game that introduces an additional layer of strategy and decision-making. This project combines game logic, strategic planning, and artificial intelligence to create a more challenging gaming experience.

The AI opponent uses the **Minimax algorithm** to evaluate possible moves, explore future game states, and select optimal moves based on the game's rules and winning conditions.

## Features

- **Super Tic-Tac-Toe Gameplay:** Implements an extended version of the classic Tic-Tac-Toe game.
- **AI Opponent:** Allows players to compete against an artificial intelligence agent.
- **Minimax Algorithm:** Uses adversarial search to evaluate possible moves and make strategic decisions.
- **Game State Evaluation:** Analyzes board configurations to identify winning opportunities and prevent potential losses.
- **Strategic Decision-Making:** Considers possible future moves to improve the AI's performance.
- **Interactive Gameplay:** Provides a way for players to interact with the game and test their strategies.

## AI Algorithm: Minimax

The core AI component of this project is the **Minimax algorithm**, a decision-making algorithm commonly used in two-player, turn-based games with opposing objectives.

The algorithm works by exploring possible future game states and assigning values to potential outcomes.

- **Maximizing Player:** Attempts to choose moves that maximize the evaluation score.
- **Minimizing Player:** Attempts to choose moves that minimize the evaluation score.
- **Game State Evaluation:** Assigns scores to terminal states or evaluates positions according to the implemented game logic.
- **Optimal Move Selection:** Selects the move with the best outcome under the algorithm's search assumptions.

By applying Minimax, the AI can plan ahead, recognize favorable positions, and respond strategically to the player's moves.
